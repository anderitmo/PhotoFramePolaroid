# Polaroid Frame
---
## Contexto
Crie uma **aplicação SPA** para capturar uma imagem pela camera do dispositivo e acrescentar um frame estilo polaroid.

## Requisitos
1. O usuário dá permissão para camera.
2. A aplicação captura a imagem
3. A aplicação acrescenta um frame estilo Polaroid na imagem
4. A aplicação permite o download


## Recursos Adicionais
1. A aplicação permite criar um mural das fotos registradas
2. O usuário pode escolher a cor do frame
3. Se houver viabilidade, criar um mural com as imagens registradas na sessão.
4. O usuário pode escolher a disposição do mural.

## Stack
* Html, CSS e JS puro (Vanilla),
* Utilize bibliotecas populares para reduzir código, erros e manutenção.
* Vou hospedar no Git Pages.
* Não gere dependencias como node, react, etc...

## UI / UX
* Mobile First,
* Interfaces minimalistas e limpas, fundo branco com cores neutras,
* Efeitos em botões e outros componentes.

## Instruções para Agentes de IA
1. Analise sempre a viabilidade do desenvolvimento.
2. Não havendo viabilidade, não execute a tarefa e solicite interação humana.
3. Todo ajuste, correção, incrementação, registre em um arquivo de backlog. Salve o arquivo em `/spec/backlog.md` registrando a data, a hora e a tarefa executada.
